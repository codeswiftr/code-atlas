## Usage Notes

- Personalize the [COMPANY], [NAME], and [PROJECT/TOPIC] placeholders before sending
- For cold email, A/B test subject lines -- the current one is conversational; try a more direct alternative like "Code Atlas pilot -- free Pro access for your team"
- For Reddit/HN, only post when genuinely relevant to the thread topic; avoid drive-by promotion
- Track which template and channel each response comes from to measure conversion by source
