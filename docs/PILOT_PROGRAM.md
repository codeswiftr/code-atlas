# Code Atlas Pilot Program

## Overview

The Code Atlas pilot is a **2-week, no-cost trial** of Pro-tier features for qualifying development teams. Participants get full access to codebase knowledge graphs, session history search, and team collaboration -- in exchange for structured feedback that shapes the product roadmap.

## Who We're Looking For

- Teams with **3 or more developers** actively using Claude Code
- Any stack, any industry -- we care about session volume, not language
- Willingness to commit ~1 hour total over the two weeks (onboarding + feedback)

Ideal participants: engineering teams that run 10+ Claude Code sessions per week and want better visibility into what the AI is doing across their codebase.

## What Participants Get

| Benefit | Details |
|---------|---------|
| **Pro features, free** | Full Pro tier ($29/mo value) for the entire pilot -- knowledge graphs, advanced search, session analytics |
| **Direct support** | Dedicated Slack channel or email thread with the Code Atlas team; responses within 4 hours on business days |
| **Roadmap influence** | Feature requests from pilot participants get priority scoring; we will share the roadmap and take votes |
| **Early adopter pricing** | Pilot graduates lock in 30% off Pro or Team pricing for 12 months |

## What We Need From Participants

| Commitment | Time | Details |
|------------|------|---------|
| **Onboarding call** | 30 min | Walk through setup, answer questions, set expectations |
| **Weekly feedback** | 15 min | Short survey (5 questions) + optional async notes in Slack |
| **Session data opt-in** | -- | Anonymous, aggregated session metadata (no source code leaves your machine) to help us improve graph quality |
| **Exit interview** | 20 min | End-of-pilot call to review experience, discuss retention |

Session data opt-in is optional but strongly encouraged. All data handling follows our privacy policy -- no source code is transmitted, only structural metadata (file paths, session durations, tool usage patterns).

## Success Criteria

| Metric | Target |
|--------|--------|
| Participating teams | 5 |
| Active users (used product 3+ days in a week) | 20+ |
| Net Promoter Score | > 40 |
| Feature requests collected | 15+ |
| Pilot-to-paid conversion | 40%+ |

## Timeline

| Phase | Duration | Activities |
|-------|----------|------------|
| **Recruitment** | 1 week before pilot start | Outreach, screening calls, account provisioning |
| **Onboarding** | Days 1-2 | 30-min calls, setup verification, first graph generation |
| **Active pilot** | Days 3-12 | Normal usage, mid-point survey (day 7), async support |
| **Wrap-up** | Days 13-14 | Exit interviews, NPS survey, conversion offers |

**Start date**: Pilot begins when FalkorDB is deployed to production and graph generation is verified end-to-end. Target: within 1 week of deployment completion.

## How to Apply

Teams can express interest by:

1. Emailing **pilot@codeatlas.dev** with team size, primary language/stack, and estimated weekly Claude Code session count
2. Filling out the interest form at **codeatlas.dev/pilot**
3. Responding to any outreach from the Code Atlas team

We review applications on a rolling basis and aim to respond within 48 hours.

## Internal Notes

- Pilot slots are limited to 5 teams in the first cohort to keep support quality high
- If demand exceeds capacity, waitlisted teams get priority for cohort 2
- All pilot feedback is tracked in the `pilot-feedback` tag in the issue tracker
- Post-pilot retrospective within 3 days of conclusion to decide on program adjustments
